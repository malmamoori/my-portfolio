File Organizer

A simple and efficient desktop application that helps users organize their files quickly and keep their folders clean.

About This Project

File Organizer is a desktop application built with Python and CustomTkinter. It allows users to select a folder and automatically organize files into categories based on their file types.

The application also handles duplicate files by automatically renaming them, preventing existing files from being overwritten.

Key Features

📁 Automatic Organization

Automatically organizes files into folders based on their file type.

🖱️ Easy Folder Selection

Select any folder easily through a simple graphical interface.

📄 Multiple File Types

Supports images, documents, music, videos, text files and shortcuts.

🔄 Duplicate Protection

Automatically renames duplicate files to prevent overwriting existing files.
