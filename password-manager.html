Password Manager

Python • CustomTkinter • SQLite • Fernet

Secure Desktop Password Manager

A desktop password manager built with Python and CustomTkinter for securely storing, managing and retrieving account credentials.

About This Project

Password Manager is a desktop application built with Python and CustomTkinter for securely storing and managing login credentials.

Passwords are encrypted using Fernet encryption before being stored locally in an SQLite database.

Key Features

🔐 Encrypted Storage

Protect saved credentials with Fernet encryption before storing them locally.

🔑 Strong Password Generator

Generate strong random passwords for new accounts.

🗂️ Credential Management

Add, update, delete and organize login credentials in one central place.

🔎 Quick Search

Find saved accounts quickly using the built-in credential search.

Technologies Used

Python CustomTkinter SQLite Fernet Encryption
